01

能力清单

  • API

    统一响应与分页

    ApiResponse / PageResponse / ResultCode，错误码与 HTTP 状态对齐（400 / 404 / 405 / 409 / 500）。

  • EX

    全局异常处理

    校验失败、非法 JSON、资源不存在、唯一约束冲突均有确定映射，并发邮箱冲突兜底为 409。

  • LAYER

    按层分包结构

    common（api / config / exception）与 module/<feature>，示例业务 User 完整走通 Controller → Service → Repository。

  • DOC

    OpenAPI 与健康检查

    Swagger UI、OpenAPI JSON、Actuator health 开箱可用，便于联调与探活。

  • TEST

    测试与 CI

    MockMvc 覆盖 CRUD 与主要错误路径；GitHub Actions 在 push / PR 时执行 ./mvnw -B verify。

  • CFG

    配置边界清晰

    仓库仅含默认可运行配置；本地密钥与连接信息走 .env 与 application-local.yml，已忽略提交。

02

快速开始

build ./mvnw clean package
run ./mvnw spring-boot:run
test ./mvnw test
swagger http://localhost:8080/swagger-ui.html
health http://localhost:8080/actuator/health
03

示例接口

方法 路径 说明
POST /api/users 创建用户
GET /api/users/{id} 按 ID 查询
GET /api/users?page=0&size=10 分页列表
PUT /api/users/{id} 更新用户
DELETE /api/users/{id} 删除用户
